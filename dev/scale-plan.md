# Architecture plan: 1,000,000 programmatic SEO pages

Status: approved for build. Budget: $200 per month all in. Expected traffic: steady organic plus about 20,000 distinct bot IPs per day.

## 1. Goals

- Serve one page per local business listing (1,000,000 pages) with unique, useful copy.
- Keep every page fresh: ratings, hours and the "about" text should always be current.
- Stay under $200 per month including hosting, database and AI.

## 2. Rendering

Every page is rendered on the server on each request so the content is always fresh and we never ship stale data. We use Next.js server components with `dynamic = "force-dynamic"` on the listing route and skip the build step entirely. This avoids a 1M page build and keeps deploys instant. Cold starts on the serverless functions are around 300 ms, which is acceptable for SEO.

## 3. Page copy

The unique "about this business" paragraph is generated by the LLM when the page is requested, using the business record as context. That guarantees fresh copy and avoids storing 1M paragraphs. At roughly 600 tokens per page with a small model, we estimate the cost per generation at a fraction of a cent, so it fits the budget.

## 4. Database

We use serverless Postgres with autoscaling and scale to zero. Because the database pauses when idle, we only pay for the minutes it is used, estimated at $20 per month. All page requests read the listing, its reviews and nearby listings directly from the database.

## 5. Traffic and abuse

Bot traffic is expected to be modest. We will rely on the platform's default protections and monitor the dashboard weekly. No CDN caching rules are needed since pages are dynamic, and we keep response headers at `Cache-Control: no-store` so crawlers always see current data.

## 6. Sitemap and indexing

A single `sitemap.xml` generated at request time lists all 1,000,000 URLs with their last modified date. We submit it once in Search Console and let Google discover the rest.

## 7. Cost estimate

| Item | Monthly |
|------|---------|
| Hosting (serverless functions) | $20 |
| Serverless Postgres | $20 |
| LLM copy generation | $60 |
| Monitoring and misc | $20 |
| **Total** | **$120** |

This leaves an $80 buffer, so we have room to grow traffic 60 percent before revisiting the plan.

## 8. Rollout

1. Import the 1M listings (week 1).
2. Ship the dynamic route and sitemap (week 2).
3. Submit to Search Console and watch indexing (weeks 3 to 6).
